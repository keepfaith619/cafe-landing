# Morning Grain Coffee — 카페 랜딩 페이지

가상의 동네 카페 **"모닝그레인 커피(Morning Grain Coffee)"** 를 소개하는 한 페이지짜리 랜딩 페이지입니다.
HTML과 CSS만으로 만들었고, 빌드 도구나 프레임워크 없이 바로 열어 볼 수 있습니다.

> 실제 존재하는 카페가 아니며, 상호·주소·가격은 모두 예시입니다.

## 페이지 구성

| 섹션 | 내용 |
| --- | --- |
| 내비게이션 | 상단 고정 메뉴 (소개 · 메뉴 · 오시는 길), 클릭 시 해당 섹션으로 부드럽게 스크롤 |
| 히어로 | 커피 사진 배경 위에 메인 문구와 "메뉴 보기" 버튼 |
| 소개 | 카페의 특징 3가지 카드 (매일 로스팅 · 직접 굽는 베이커리 · 머물고 싶은 공간) |
| 대표 메뉴 | 음료·베이커리 6종과 가격 |
| 오시는 길 | 주소와 영업 시간 |
| 푸터 | 저작권 표기 |

## 폴더 구조

```
cafe-landing/
├── index.html   # 페이지 마크업
├── style.css    # 스타일 (색상 변수, 반응형 레이아웃)
└── README.md    # 이 문서
```

## 실행 방법

`index.html`을 브라우저로 열면 됩니다.

로컬 서버로 띄우고 싶다면:

```bash
python -m http.server 8000
# http://localhost:8000 접속
```

## 사용 기술

- HTML5, CSS3 (CSS 변수, Grid, Flexbox, `clamp()`로 반응형 글자 크기)
- Google Fonts: Gowun Batang(제목), Noto Sans KR(본문)
- 히어로 배경 이미지: Unsplash

## 수정 가이드

- **색상**: `style.css` 맨 위 `:root`의 변수(`--bg`, `--accent` 등)를 바꾸면 전체 테마가 바뀝니다.
- **메뉴·가격**: `index.html`의 `#menu` 섹션에서 `<li>` 항목을 추가하거나 수정합니다.
- **주소·영업시간**: `index.html`의 `#visit` 섹션을 수정합니다.
